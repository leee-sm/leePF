# 화면과 편집기 설계

## 1. 메뉴와 경로

| 경로 | 화면 | 접근 |
|---|---|---|
| /dashboards | 대시보드 목록 | 로그인 사용자 |
| /dashboards/:id | 공개 대시보드 조회 | 로그인 사용자 |
| /admin/dashboards | 관리 목록 | 관리자 |
| /admin/dashboards/new | 생성 | 관리자 |
| /admin/dashboards/:id/edit | 편집·미리보기 | 관리자 |

왼쪽 사이드바에는 서비스 표시명과 실제 경로가 있는 대시보드·관리 메뉴를 둔다. 상단에는 현재 워크스페이스, 사용자 이름·사번, 로그아웃을 표시한다. 로그인 후 기본 진입은 /dashboards다.

데스크톱에서는 사이드바를 고정하고 대시보드 본문을 카드 격자로 배치한다. 모바일에서는 메뉴를 상단 가로 메뉴로 접고 위젯을 한 열 또는 두 열로 재배치한다. 관리자 편집기는 설정 패널을 아래로 이동하고 위젯 선택기를 오른쪽 드로어로 연다.

## 2. 이용자 목록

카드에 제목, 설명, 공개 설정 변경 시각을 표시한다. 설정 변경 시각을 데이터 최신 시각처럼 표시하지 않는다. 제목 검색과 최근 공개순 정렬을 제공한다.

공개된 항목이 없으면 ‘공개된 대시보드가 없습니다’라고 안내한다. 관리자는 관리 화면으로 이동할 수 있다. 원천 데이터는 목록 진입 시 호출하지 않는다.

## 3. 이용자 상세

```text
[목록으로]  재고 현황                                      [새로고침]
설명
[시작일 달력] [종료일 달력] [제조사 ▾] [모델 ▾]      [초기화] [조회]
조회 기간·원천 갱신·조회 시각
┌────────────┬────────────┬──────────┬──────────┐
│ 종료일 수량  │ 기간 변화   │ 제조사 수 │ 모델 수   │
└────────────┴────────────┴──────────┴──────────┘
┌──────────────────────────────────┬─────────────────┐
│ 선택 기간 재고 추이                 │ 집중도 / 도우미   │
└──────────────────────────────────┴─────────────────┘
┌──────────────────────────────────────────────┐
│ 제조사별 차트 / 모델별 상위 10개 차트 / 집계 표 │
└──────────────────────────────────────────────┘
```

재고 조회 조건은 시작일·종료일 달력 입력과 제조사·모델 필터다. 달력은 실제 조회 가능한 스냅샷 날짜만 허용한다. 기본 기간과 ‘기간·분류 초기화’는 가장 이른 조회 가능일부터 가장 늦은 조회 가능일까지 돌아간다. 시작일이 종료일보다 늦으면 고정 안내 영역에 이유를 표시하고 조회를 막는다. 조건 변경은 ‘조회’를 눌러 적용하고, 그 전까지 마지막 성공 결과를 유지한다. ‘새로고침’은 마지막 적용 조건으로 재조회한다.

개요의 재고 카드·분류별 차트·표는 종료일 스냅샷 기준이다. 기간 변화는 시작일과 종료일에 같은 제조사·모델 조건을 적용한 수량 차이다. 추이 그래프에는 선택 기간 안에서 실제 제공된 스냅샷만 표시하며 날짜·수량 목록을 함께 제공한다. 날짜별 스냅샷을 합산하지 않는다. 정상 0건은 그래프와 요약에 0으로 표시하며 조회 실패 상태와 분리한다. 미등록 분류는 별도 수량으로 표시하고 전체 재고에서 제외하지 않는다. 차트 항목이나 표 행을 누르면 분류 조건을 편집 상태로 바꾸며 조회를 눌렀을 때 새 결과를 적용한다.

조회 조건 패널은 상단 내비게이션 아래에 sticky로 유지한다. 모바일에서는 날짜와 분류 필터를 두 열로 배치하고 화면 폭을 넘기지 않는다. 상태 안내 영역 높이를 예약해 조건·조회 버튼의 위치를 유지한다. 조회 중에는 마지막 성공 결과를 유지하고 갱신 중임을 표시한다. 실패하면 기존 결과를 유지하고 다시 시도할 수 있게 한다. 먼저 보낸 요청은 취소하거나 응답을 무시한다. 표의 정렬·페이지 변경은 해당 표만 갱신한다.

내보내기는 현재 종료일의 요약, 선택 기간 스냅샷 추이, 표시 중인 분류 항목을 UTF-8 CSV로 저장한다. 집계 표는 전체 행과 페이지 정보를 포함한다.

## 4. 관리자 목록과 생성

관리 목록 열: 제목, 데이터 소스, 상태, 미공개 변경 여부, 마지막 수정자·시각, 동작.
검색과 상태 필터를 제공하며 행 동작은 편집·공개 화면 보기·공개 중지·삭제다.

‘새 대시보드’ 화면은 제목(필수), 설명(선택), 데이터 소스(필수)를 받는다. 첫 PoC의 등록 소스는 재고 하나이며, 재고 템플릿을 선택하면 위젯 4개와 필터 3개가 채워진 초안으로 시작한다. 관리자는 이를 수정·삭제할 수 있다. ‘만들기’로 서버에 초안을 저장한 뒤 편집기로 이동한다. 빈 초안 저장도 허용하지만 공개는 막는다.

데이터 소스가 없거나 비활성화되어 있으면 생성할 수 없고 담당자 확인 안내를 보여준다. 연결 URL과 비밀정보 입력란은 제공하지 않는다.

## 5. 편집기

```text
[관리 목록] 제목   [초안/공개·미공개 변경] [저장] [미리보기] [공개]
┌────────────┬───────────────────────────┬──────────────────┐
│ 위젯 추가   │ 편집 화면                  │ 선택 항목 설정    │
│ 지표 카드   │ [위젯 A]  [위젯 B]         │ 제목             │
│ 막대 차트   │ [위젯 C             ]      │ 지표·분류         │
│ 집계 표     │                           │ 정렬·폭           │
│ 공통 필터   │                           │ [위로][아래로]    │
│            │                           │ [삭제]            │
└────────────┴───────────────────────────┴──────────────────┘
```

- 상단의 ‘위젯 추가’를 누르면 배경을 어둡게 하고 오른쪽 선택 패널을 연다. 유형 카드의 ‘선택’을 누르면 마지막 위치에 위젯을 추가하고 우측 설정을 연다. 패널은 닫기 버튼, 바깥 영역 클릭, Escape 키로 닫는다.
- 중앙에서 위젯을 선택하면 해당 설정을 편집한다.
- ‘위로/아래로’는 표시 순서, 폭 선택은 격자 너비를 바꾼다.
- 높이는 위젯 유형별 기본값을 사용한다. 임의 픽셀 입력은 받지 않는다.
- 위젯 삭제는 편집 상태에서 제거하며 서버 반영은 저장 시점이다.
- 데이터 소스 변경은 기존 위젯·필터를 초기화한다는 확인 후 적용한다.
- 초기에는 명시적 저장을 사용한다. 저장 전 이탈 시 확인창을 표시한다.

편집 중에는 예시 배치와 마지막 미리보기 결과를 보여준다. 설정을 바꾸면 이전 미리보기에 ‘갱신 필요’를 표시한다. 입력할 때마다 원천 API를 호출하지 않는다.

## 6. 위젯 설정 상세

공통 설정은 고유 ID(서버/앱 생성), 유형, 제목, 폭, 순서다. 제목을 비워두면 선택한 지표·분류의 표시명을 기본 사용한다.

| 유형 | 필수 설정 | 선택 설정·검증 |
|---|---|---|
| 카드 | 지표 | 단위, 소수점 0~2자리; 업무 단위 변경은 불가 |
| 막대 | 분류 1개, 지표 1개 | 값 오름/내림차순, 상위 5/10/20개 |
| 표 | 분류 1~3개, 지표 1~3개 | 표시 열 내 정렬, 페이지 크기 20/50/100 |

소수점 설정은 표시 반올림이며 서버 원값을 바꾸지 않는다. 초기 차트 팔레트는 서비스 공통값을 사용한다. 색상·축·formatter의 자유 편집은 제공하지 않는다.

기본 스타일은 밝은 배경, 흰 위젯 카드, 하나의 주요 강조색으로 통일한다. 화면 바깥 여백은 24px, 위젯 간격은 16px를 기본으로 하고 표 숫자는 우측 정렬한다. 상태색은 성공·경고·실패에만 일관되게 사용한다. 지표 카드와 차트·표의 높이는 각각 유형별 공통값으로 맞추고 표는 내부 스크롤·페이지 처리를 사용한다.

지원하지 않는 지표·분류 조합은 선택 단계에서 안내하고 서버에서도 거부한다. 실제 0은 0으로 표시하고 계산 불가는 ‘—’와 이유를 표시한다.

## 7. 공통 필터

첫 PoC는 시작일·종료일·제조사·모델 필터를 제공한다. 시작일·종료일은 실제 스냅샷 날짜 목록에서 고르며, 기존 설정의 필수 기준일 필터를 읽어 종료일 조건으로 사용한다. 제조사·모델 표시명·기본값은 편집할 수 있고 기준일 필터는 제거할 수 없다.

기존 단일 기준일 기본값 설정은 이전 대시보드와의 호환을 위해 읽을 수 있다. 이용자 화면의 새 기본 범위는 조회 가능일 2026-09-08부터 2026-09-10까지이며, 09-08은 정상 0건으로 표시한다. 선택 기간 그래프는 실제 스냅샷만 표시하고 나머지 요약·차트·표는 종료일 기준이다.

선택지는 서버가 허용된 필드 값으로 제공한다. 첫 버전에서는 서로 종속되는 필터를 만들지 않는다. 범주 필터의 빈 선택은 전체이며, 사용 불가능해진 기본값은 자동 변경하지 않고 수정 안내를 표시한다.

## 8. 미리보기·저장·공개

미리보기는 저장하지 않은 현재 설정을 서버에 보내 검증·조회한다. 이용자 화면과 동일한 렌더러를 쓰며 관리자 전용 ‘미리보기’ 표시를 둔다. 편집기 복귀 시 입력을 유지한다.

저장은 구성 유효성을 확인하되 비어 있는 새 초안은 허용한다. 원천 장애 중에도 구조적으로 유효한 초안 저장은 가능하다. 저장 성공 시 버전을 갱신하고 변경 표시를 해제한다.

공개 버튼은 미저장 변경이 있으면 ‘저장 후 공개’를 안내한다. 공개 확인창에는 제목, 위젯 수, 데이터 소스와 ‘활성 SSO 사용자 전체’ 공개 대상을 표시한다. 서버가 저장된 초안을 재검증·조회한 뒤 공개한다. 실패하면 기존 공개본을 유지하고 원인과 수정할 항목을 알려준다.

공개 중지 확인창은 이용자 접근이 즉시 차단됨을 안내한다. 삭제 확인창은 복원 기능이 없음을 안내하며 공개 상태에서는 먼저 공개 중지를 요구한다.

## 9. 예외와 사용자 피드백

| 상황 | 화면 처리 |
|---|---|
| 조회 중 | 마지막 성공 결과 유지, 갱신 중 표시 |
| 정상 0건 | 조건에 맞는 데이터 없음; 카드 건수 0, 비율은 분모에 따라 계산 불가 |
| 원천 장애 | 조회 실패·다시 시도; 마지막 성공 조회 결과임을 표시 |
| 설정이 원천과 맞지 않음 | 이용자에게 조회 불가, 관리자에게 영향 위젯·필드 안내 |
| 세션 만료 | 로그인 안내; 편집 중이면 현재 탭의 입력 상태 유지, 재로그인 후 버전 재확인 |
| 저장 충돌 | 자동 덮어쓰기 금지, 입력 유지 후 최신본 다시 불러오기 선택 |
| 공개 중지·삭제됨 | 접근할 수 없음과 목록 이동 |
| 저장 실패 | 입력 유지, 재시도 제공 |
| 권한 없음 | 관리 화면 접근 불가; 서버도 403 처리 |

업무 데이터와 편집 내용을 localStorage에 자동 저장하지 않는다. 전체 페이지 새로고침 시 미저장 입력은 잃을 수 있음을 이탈 안내에 표시한다. 입력 레이블, 키보드 조작, 수치 단위와 색상 외 상태 문구를 제공한다.
